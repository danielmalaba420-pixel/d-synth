D-SYNTH by Danova — Mac (Apple Silicon et Intel)

1. Double-clique sur « Installer D-SYNTH.command ».
   Si le Mac bloque l'ouverture : clic droit sur le fichier > Ouvrir > Ouvrir.
2. Relance Logic Pro : piste instrument > AU Instruments > Danova > D-SYNTH.
   Autres logiciels (Ableton, Studio One, FL Studio...) : VST3 > D-SYNTH.
3. Sans logiciel : ouvre D-SYNTH dans le dossier Applications.

Les 12 sons : Rising Run, The Run, Gospel Square, Soft Sine, Flute Synth, Whistle,
Supersaw, Finger Bass, Afro Pluck, String Glide, Elle Glide, Glide Sine.

Molette : Build sur Rising Run, tremolo sur Elle Glide, vibrato sur les autres.
CHORD GLIDE (sur String Glide, Elle Glide et Glide Sine) : vitesse du glissement entre les accords.

Finger Bass : vraie basse aux doigts, chaque note est pincée sur la corde (joue dans le grave).
